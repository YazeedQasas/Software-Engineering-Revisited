# Changelog

All notable changes to this project are logged here, newest first.

## [Unreleased]

### Added

- **Stacks & Queues** page: LIFO vs. FIFO fundamentals, implementing a
  queue from two stacks, monotonic stacks for the next-greater-element
  pattern, and deques — each backed by real Python, an animated diagram,
  a cheat sheet, and an 8-question self-quiz.
- Sidebar restructured into routed sections — **Data Structures**,
  **Algorithms**, **Patterns** — each with its own grouped outline in a
  second sidebar panel, title-only placeholders ready to fill in.
- Data Structures' outline expanded: Recursion moved under Foundation,
  several topics relabeled for precision (Complexity Analysis, Hashing,
  Linked Lists, Binary Trees, Graphs), new placeholder topics added
  (Matrix, Balanced Trees, Segment Tree & Fenwick Tree), and "Stacks &
  Queues" split into three separate entries — Stacks, Queues, Deques —
  all still backed by the existing combined page.

### Changed

- Narrowed active focus to **Data Structures** and **Algorithms**
  (starting with Searching & Sorting), written for a beginner audience.
