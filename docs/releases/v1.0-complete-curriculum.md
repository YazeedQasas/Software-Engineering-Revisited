**Type:** Major (first major version)
**Version:** 1.0
**Date:** 2026-10-21
**Source plan:** https://roadmap.sh/datastructures-and-algorithms
**Language:** Python

## What 1.0 means

Software Engineering Revisited was planned in 0.0 as one route through the
roadmap.sh Data Structures & Algorithms roadmap, split into 9 sections. Every
release since then wrote one more part of it. 1.0 is the point where the last
section is done: **all 41 topics across the 9 sections have a written page, and
no placeholder pages are left.** It is the first version that covers the whole
plan, which is why it is the first major version.

## What a page looks like

Every topic is explained from first principles for a beginner. Most pages have
real Python that was run, small animated or step-through diagrams, a cost table,
a one-sentence definition, when to reach for it, and an 8-question quiz where
you guess the time and space complexity before the answer is revealed, and many
also have an interactive code tracer that plays the real code line by line next
to a picture of the data. The Problem Solving page is the exception: it is a
list of techniques, each with a small picture and a short piece of code.

## New in this release

- **Problem Solving Techniques**, rebuilt as a plain list of 16 techniques in
  three groups. Each has its title, what it is, how it works and where it is
  usually used, then a small isometric picture that you step through with back
  and next arrows (nothing plays by itself), then a short piece of Python.
- **Island counter**: an interactive step-through of the "count islands"
  algorithm (the Island Traversal technique), with Next step, Play / Pause,
  Reset and keyboard control.
- **Multi-threaded** now explains race conditions and the three ways to prevent
  them: mutex / locking, atomic operations and data isolation.
- **Unit tests** for the island step builder, run with `npm test` (Node's
  built-in test runner, so no new dependency).
- **Layout stability**: the code tracer reserves room for the longest variables
  row and note of the steps it plays, so the page no longer jumps while a tracer
  runs.

## Known gaps

- The **Big-O** page was written before the page structure settled, so it is
  the one page that does not yet follow it (recap, definition, costs, quiz).
  Rebuilding it is the next piece of work.
- Pages from 0.8 and earlier still loop their animations on their own, while
  the Problem Solving pictures are stepped by hand. Their animations also
  still change height slightly from frame to frame (the tracers no longer do).
- Automated tests so far cover only the island step builder.
- The old **Strings** page is not linked from the sidebar. Its files are still
  in the repo.
